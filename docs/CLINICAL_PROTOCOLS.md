# Clinical Protocols
Child: 14 Well-Child Visits 1mo-6y — growth, milestones, immunization, hearing, vision.
Adult: IFHAS — MoCA + hearing + vision + metabolic + sleep + mood. Start at 50 to normalize, reduce stigma.
Interpretation: Always vs personal baseline, adjust for language/education/hearing/vision/mood/sleep/digital familiarity.
Escalation: REFER requires clinician review. Red flags auto-escalate.
